How to use a zoom-on-click screen recorder in Chrome

Published October 10, 2026 · Click & Record team

A zoom on click screen recorder for Chrome is a browser extension that records your screen and automatically zooms the video toward each click. With Click & Record, you install the extension, pick a tab, window or screen, record normally, and the editor opens with a zoom already placed on every click, each one adjustable or removable. It is free, needs no account, and adds no watermark.

This is the hands-on guide: setup, how to perform a take so the zooms land well, and how to tune them afterwards.

Before you start: requirements

  • Browser: Chrome, Edge or Brave, version 116 or newer (check at chrome://settings/help).
  • What gets zoomed: clicks inside web pages. You can record any window or your whole display, but clicks in non-browser apps produce no automatic zoom.
  • Optional: a microphone for narration and a webcam for a face bubble.

Set up a zoom on click screen recorder in Chrome

  1. Install the extension from the Chrome Web Store and pin it to the toolbar so the icon is always one click away.
  2. Open the page you want to demo. Log in, close stray tabs and dismiss cookie banners now, not mid-take.
  3. Click the toolbar icon and choose the source: this tab, a window or a whole screen. For browser-only demos, a tab gives the cleanest result; see how to record a Chrome tab.
  4. Turn on mic or webcam if you want them. The webcam is stored as its own track, so you can restyle or hide it later.
  5. Start recording. A 3-2-1 count-in runs first and is not included in the file.
  6. Stop from the toolbar icon or with Alt+Shift+S. The editor opens with zooms already generated.

How the click zoom behaves

Knowing the rules helps you record a take that needs little cleanup.

What you doWhat the zoom does
Single clickEases in toward the click point, holds, eases out.
Several clicks in quick successionClicks inside an in-flight zoom are skipped, so bursts do not stack into a jittery mess.
Two clicks close together in timeThe zooms link, and the camera pans from one point to the next while staying zoomed in.
Click a field, then typeThe zoom holds for the whole typing burst. Only timing is recorded, never the characters.
Click in a desktop app (not a web page)No automatic zoom. Add a manual zoom in the editor if needed.

Because the zooms are generated after you stop, recording itself is unaffected: the raw file is a normal full-frame capture, and the zooms are keyframes on top. For the concept in more depth, read what an auto-zoom screen recorder is.

Recording technique for clean zooms

Zoom on click rewards a calm, intentional take. A few habits make a big difference.

Click with purpose

Every click is a candidate zoom. Avoid clicking empty space to "focus" a window or out of habit while you talk. If you need to focus a page, do it before you start recording.

Let each zoom land

After an important click, pause about a second before the next action. That gives the zoom time to ease in and the viewer time to see what changed.

Move the mouse less

Big sweeping cursor movements between clicks look busy when the frame is zoomed. Move directly to the next target.

Size the window sensibly

A 1280 to 1600 pixel wide browser window keeps UI elements large enough to stay sharp when zoomed, while still looking like a real desktop. Very large windows make text small; very small ones look cramped.

Use pause instead of retakes

If you need to look something up or wait for a slow process, pause the recording and resume when ready. If the browser crashes mid-take, the recording is written to disk continuously and the popup offers to recover it.

Fine-tune zooms in the editor

The generated zooms are a first draft. Spend a few minutes on one review pass:

  • Delete zooms on incidental clicks such as closing a tooltip or clicking into the address bar.
  • Retime a zoom that arrives late or leaves while the viewer is still reading.
  • Re-aim a zoom so it centers on the result, not the button, when the result is what matters.
  • Strengthen or weaken individual zooms: stronger for tiny icons, weaker for wide panels.
  • Add manual zooms for moments with no click, like a value updating or a notification appearing.

Then trim the start and end, speed up slow sections (0.5x to 4x per clip), and optionally add a background, rounded corners and a browser frame. The mock frame has an editable URL bar, which is handy for hiding a staging URL.

Export settings that suit zoomed video

  • Format: MP4 (H.264 + AAC) for maximum compatibility, or WebM (VP9 + Opus) for web embeds. See MP4 vs WebM for screen recordings.
  • Aspect ratio: 16:9 for YouTube and docs, 9:16 for Shorts and Reels, 1:1 or 4:5 for feeds. Zooms matter even more in narrow frames.
  • Quality: the export dialog shows resolution, bitrate and estimated file size before you commit, so you can pick a preset that fits your upload limit.

Everything, including export, runs locally in your browser. Nothing is uploaded unless you choose Save to Google Drive.

Where zoom on click fits best

Zoom on click shines for product demos, feature announcements, onboarding videos and tutorials, where each click is a step the viewer should follow. If you are planning a full demo, how to make a product demo video covers scripting and structure. For quick bug reports, you might delete the zooms and keep the full frame so developers see everything.

Install the extension, record one short take of a real workflow, and review the zooms it produces. Most people find the first draft is close, and a two-minute cleanup gets it the rest of the way.

Frequently asked questions

Does zoom on click work when I record my whole screen?

Yes, for clicks inside web pages in Chrome. An extension cannot see clicks in other desktop apps, so those moments need a manual zoom added in the editor.

Will the zoom capture what I type?

No. Click & Record only records the timing of typing bursts so it can hold the zoom while you type. The actual keys are never recorded.

Can I record without any zoom?

Yes. Zooms are added after recording, so you can delete all of them and export the plain, full-frame video.

Which browsers does it work in?

Click & Record runs in Chrome, Edge and Brave on Chromium 116 or newer. It does not run in Firefox or Safari.
